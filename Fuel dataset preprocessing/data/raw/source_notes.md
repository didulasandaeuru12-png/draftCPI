# Fuel source snapshots

CPC historical prices: https://ceypetco.gov.lk/marketing-sales/historical-prices
API: https://api.ceypetco.gov.lk/api/admin/historical-prices/active
Retrieved: 7 November 2026. Fuel rows and fields are retained from the original snapshot; no prices or dates are filled.

Additional file: fuel-prices-2026-10-15.csv, supplied locally by the user.
Publisher page: https://research.dulajmendis.com/data/fuel-prices/
The filename identifies the supplied release, not a fresh retrieval on this update. Original status, unit, geography and source fields are retained. Only Auto Diesel, Super Diesel and Kerosene are reconciled into the working data. This compilation shares CPC provenance; it is not an independent measurement source.

The malformed furnace-oil value 53.9.00 on 6 December 2008 is preserved raw and withheld from numeric analysis. Exact original source files are in the pre-update backup. Source licences are not inferred from file availability.
